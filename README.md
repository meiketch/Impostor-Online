# Impostor Game

Ein simples Impostor-Spiel für Android.

Dieses Projekt ist **100% vibe coded**. Es gibt keine Garantie, dass der Code schön, sauber oder überhaupt sinnvoll aussieht – aber er funktioniert. (Meistens.)

## Features

* Lokales Impostor-Spiel für Gruppen
* Zufällige Rollenverteilung
* Über 1000 Begriffe
* Einfache Bedienung

## Download

Wenn du keine Lust hast, das Projekt selbst zu kompilieren (oder genauso wenig Ahnung davon hast wie ich), dann lade einfach die **APK** aus diesem Repository herunter.

## Kompilieren

Falls du das Projekt selbst bauen möchtest:

1. Repository klonen.
2. Mit Android Studio öffnen.
3. Build ausführen.
4. Hoffen, dass nichts explodiert.

## Hinweis zur Wortliste

Die Wortliste enthält über **1000 Begriffe**. Ehrlich gesagt sind einige davon ziemlich speziell oder einfach komisch.

Falls euch beim Spielen Wörter auffallen, die niemand kennt oder die keinen Sinn ergeben, schaut gerne mal durch die Liste und verbessert sie per Pull Request oder passt sie für euch selbst an.
